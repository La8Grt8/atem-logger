Quick Start

ATEM Logger

Log every switcher cut to an EDL, then rebuild the live edit in DaVinci Resolve.

Version 1.1
github.com/La8Grt8/atem-logger

ATEM Logger runs as a background service on a computer on the same network as your ATEM switcher. It records every program change (from the panel, ATEM Software Control, macros or anything else) with timecode, and saves it as an EDL for DaVinci Resolve, Premiere Pro, Avid or Final Cut Pro. Record each camera separately (HyperDecks or camera cards), then conform the EDL in your edit software against those files to get the switched show back. You control it from a web page.

1Install (one time per computer)

Mac

Download the ZIP from GitHub and unzip it somewhere permanent. Double-click Install on Mac.command and enter your Mac password. If macOS blocks it, right-click → Open.

Windows

Download the ZIP and unzip it somewhere permanent. Double-click Install on Windows.bat and click Yes for administrator rights. If SmartScreen appears, click More info → Run anyway.

Docker / ZimaBoard

Use image ghcr.io/la8grt8/atem-logger with docker-compose.yml from the repo. Map /edl to where EDLs should land.

The installers set up Node.js if it's missing, install the background service, the menu-bar/tray icon and the atem-logger command, then open the control page. Don't move the folder afterwards, because the service runs from it.

2First-time setup

  1. Switcher: open Switcher & timecode settings (bottom right), enter the ATEM's IP, and click Save settings. The pill at the top turns green with the switcher model when connected.
  2. Reel names: give each camera input a short reel (max 8 characters), e.g. CAM1, then click Save reel names. Blank uses the ATEM's short name. No two cameras may share a reel.
  3. Timecode: leave Switcher timecode selected if the cameras, HyperDecks and ATEM share the same time-of-day timecode (e.g. Tentacle Sync). Check that the status line's DF / NDF matches your camera timecode.

The control page during a show: live timecode, program/preview, recent switches, and the Stop and Add Marker buttons.

3Running a show

Before you roll

  • Header pill is green and shows the switcher.
  • Program / Preview match what's on the multiview.
  • Type the title (e.g. Episode_23) and the save folder for this episode.
  • Project drive is mounted.
  • Edit software is set to the app you'll cut in.
  • Cameras / HyperDecks are recording with synced timecode.

Roll

Click Start EDL. The page shows ● LOGGING, running timecode and the switch count. Cut the show as normal from any panel or software.

Markers

Mark a moment for the edit: a great soundbite, a retake, a clip for social.

  • Click ◆ Add Marker, or
  • press M anywhere on the page, or
  • type a note in the box under the button and press Enter.

Wrap

Click Stop EDL and confirm. Your files are in the save folder:

  • Episode_23_<date>_<time>.edl, the cuts
  • a markers file for your edit software (_markers.edl / .txt / .csv), if you added markers
  • for Final Cut, a .fcpxml

They're also listed under EDL files for download.

The EDL is saved after every cut. If the computer or app restarts mid-show, nothing already logged is lost. The page points you to the partial file, and you can start a new EDL to keep going.

4Import into your edit software

Name each camera file after its reel (CAM1.mov, CAM2.mov, CAM3.mov). Every app matches on that name.

DaVinci Resolve

  1. Project Settings: set the timeline frame rate (e.g. 29.97) before adding media. In General Options → Conform Options, tick Assist using reel names from the: Source clip filename. This is needed in every new project, so save it in your project template.
  2. Import the camera files, then go to File → Import → Timeline, pick the .edl, and untick Automatically import source clips.
  3. Markers: right-click the timeline in the Media Pool → Timelines → Import → Timeline Markers from EDL, and pick the _markers.edl.

Premiere Pro

File → Import the .edl with a matching sequence preset. Select the offline CAM clips, right-click → Link Media, keep File Name ticked, untick File Extension, then locate CAM1.mov. Marker times are in _markers.csv; Premiere can't import marker files.

Avid Media Composer

File → Import the .edl, or use EDL Manager. Link the camera files and set their Tape names to CAM1, CAM2…, then relink the sequence by tape and timecode. For markers, go to the Markers window, then Fast Menu → Import Markers and choose _markers.txt.

Final Cut Pro

The logger builds a .fcpxml from the camera files when you stop. If they weren't on the drive yet, use EDL files → Build Final Cut XML later. Then go to File → Import → XML. It opens already linked, with the markers on the clips.

Then check sync at a clap or hard consonant, and lay the separately recorded audio underneath.

5Updates

The app checks GitHub for a new version when it starts and every few hours. When there is one, the control page shows a banner (Update now · What's new · Later) and the icon asks once. Updating takes about a minute and restarts the service. It's blocked while an EDL is being logged, so it can never interrupt a show. To check yourself, go to Switcher & timecode settings → Check for updates. On Docker, run docker compose pull && docker compose up -d instead.

6Service controls

ATEM Logger runs as a background service. It starts when the computer boots, even if nobody logs in, and restarts itself within seconds if it ever crashes. You can stop it any time from the icon or the command line. It stays stopped until you start it again or the computer reboots.

Menu-bar / tray icon

On a Mac it's next to the clock. On Windows it's in the system tray (you may need the ^ arrow). The colour shows the state:

Grey: service stopped Orange: running, switcher not connected Green: running and connected, ready Red: logging (Mac also shows the switch count)

Click it to open the control page, add a marker, start/stop/restart the service, or install an update. Stopping or restarting while logging asks first and finalizes the EDL. Quit only removes the icon, and the service keeps running.

Command line

Use Terminal on a Mac, or any new terminal window on Windows.

atem-logger statusRunning or stopped, switcher connection, logging state and EDL file
atem-logger stopStop the service. Any EDL in progress is finalized first
atem-logger start · restartStart or restart it. No password needed for admins
atem-logger open · logsOpen the control page · follow the log
atem-logger disable · enableDon't start / do start at boot (asks for an admin password)

7Troubleshooting

What you seeWhat to do
Red pill: "Not connected"Check the switcher is on and the IP is right. The computer must reach the ATEM on UDP 9910, which is the same as ATEM Software Control. The app reconnects on its own.
"Switcher connection lost" during a showLogging keeps running and resumes when the switcher reconnects. Cuts made while disconnected aren't captured, so note the time.
"Could not write the EDL file"The save folder isn't reachable, usually because the drive is unmounted. Remount it. The next cut rewrites the whole file.
Everything conforms to one cameraThe Conform Option in step 4.2 isn't ticked. Tick it and import the EDL again.
Cuts land on the wrong cameraReel names don't match the file names, or two inputs share a reel. Fix them under Reel names, which applies from the next EDL.
Media offline / shots a frame or two offThe camera timecode doesn't match the EDL. Check the cameras and switcher share time-of-day timecode, and that DF/NDF matches. For a constant offset, adjust the clip's Start TC in Resolve.
Page won't open / icon is greyThe service is stopped. Click the icon → Start Service, or run atem-logger start. After a reboot with FileVault on, someone has to unlock the Mac first. Logs: ~/.atem-logger/logger.log (Mac), %USERPROFILE%\.atem-logger\atem-logger-service.out.log (Windows).
Can't save to a network drive (Windows)The service can't see mapped drive letters. Use the full share path, e.g. \\nas\projects\EDL.
Update failedThe banner shows why, and the old version keeps running. Click Try again, or re-run the installer.
